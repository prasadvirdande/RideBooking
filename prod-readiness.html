Production Readiness Improvements - RideBooking Microservices

Scope: ApiGateway, Auth-Service, user-service, driver-service, ride-service, Payment-Service, Notification-Service, Service-Discovery (AI_SERVICES excluded).

Legend: P0 = must-fix before prod   P1 = should-fix soon   P2 = nice-to-have

IssueWhereFix

6. ride-service

ImprovementPriorityDetail
Remove debug System.out.printlnP1~20 println statements in RideServiceImpl - replace with SLF4J structured logging at proper levels.
Fare/distance as server-authoritativeP0Fare is recomputed server-side (good) - ensure client can never set fare/distance; verify completeRideDTO only carries drop coords.
Ride state machine enforcementP0Centralize allowed transitions; add audit trail (who/when changed status).
Race conditionsP1updateRide/startRide/completeRide read-modify-write - add optimistic locking (@Version) or SELECT FOR UPDATE to prevent double-accept/double-complete.

Kafka consumer for payment-successP0Replace fragile sync RideClient.paymentSuccess callback - see Kafka report. Add consumer + idempotent completeRideAfterPayment.

10. Suggested Order of Work

Week 1 (P0 security/data):
  1. Move secrets to env vars + rotate exposed keys
  2. ddl-auto=validate + Flyway; disable devtools/show-sql in prod
  3. Actuator health endpoints everywhere
  4. Resilience4j timeouts/circuit breakers on Feign clients
  5. Payment webhook: amount verification + payment.captured fix + replay protection

Week 2 (P0 correctness):
  6. Ride state machine + optimistic locking
  7. Kafka: payment-success-topic + ride lifecycle events (fix driver listener bug)
  8. Notification-Service Kafka consumers (async email)
  9. Auth: refresh token rotation + login rate limiting

Week 3+ (P1/P2):
 10. Structured logging + tracing + request IDs
 11. Centralized config, API versioning, OpenAPI
 12. Real test suite for critical flows
 13. Database-per-service migration plan
 14. CI/CD pipeline + container hardening
Top 5 things that will hurt you in production first:
1. Plaintext secrets in git (Razorpay secret exposed = financial risk)
2. Shared authdb across all services (coupling + blast radius)
3. Sync payment callback with no retry (rides stuck in PAYMENT_PENDING)
4. No circuit breakers on Feign (one down service cascades)
5. payment.captured webhook bug (alternate event path always fails)
